# 声の音声ファイル

タイマーが話す声です。<audio>ではなく効果音と同じ仕組みで鳴らすので、iPhone のマナーモードでも聞こえます。
ここにファイルがない言葉は、iPhone の読み上げで話します（マナーモードでは聞こえません）。

| ファイル名 | 話す言葉 |
|---|---|
| san.wav | さん |
| ni.wav | に |
| ichi.wav | いち |
| start.wav | スタート |
| kyukei.wav | 休憩 |
| ato10.wav | あと10秒 |
| owari.wav | 終了です。お疲れさまでした |

別の声に差し替えるときは、同じ名前で置き換えます（mp3・m4a・wav のどれでも可）。
