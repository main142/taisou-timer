# 録音した声を置くフォルダ

ここに次の名前で音声ファイルを置くと、タイマーがその声で話します（マナーモードでも鳴ります）。
ファイルがない言葉は、これまでどおり iPhone の読み上げで話します。

| ファイル名 | 話す言葉 |
|---|---|
| san | さん |
| ni | に |
| ichi | いち |
| start | スタート |
| kyukei | 休憩 |
| ato10 | あと10秒 |
| owari | 終了です。お疲れさまでした |

形式は mp3・m4a・wav のどれでもかまいません（例：`san.mp3`、`start.m4a`、`owari.wav`）。
「さん・に・いち」は1秒ごとに話すので、1秒より短くしてください。
